=== Pakhsh Mahdi App Core ===
Contributors: pakhshmahdi
Tags: woocommerce, mobile, rest-api
Requires at least: 6.5
Requires PHP: 8.1
Stable tag: 0.1.0

REST bridge for the native Pakhsh Mahdi mobile applications.

Endpoints:
- GET /wp-json/pm-app/v1/home
- GET /wp-json/pm-app/v1/products
- GET /wp-json/pm-app/v1/products/{id}

This version intentionally exposes only public catalog data. Checkout/authenticated account routes are not included yet.
